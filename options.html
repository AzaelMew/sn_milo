ServiceNow Milo

    Settings are stored per browser profile (not synced). Alert notifications additionally require a completed migration (dedupe import or an explicit first-run fallback decision, offered below each pending alert); the checkbox alone never activates them.

    Critical alert rules

    A ticket in the SOC Jono queue (active, state New) triggers an alert when it matches any enabled rule. Within a rule, every filled-in field must match; leave a field on "Any" / empty to ignore it. A ticket matching several rules still alerts once. Rules are stored in this browser profile only.

    Interaction alert accounts

    One account name per line (as shown in ServiceNow). New interactions for these accounts alert; with none listed, the interaction alert does nothing. Stored in this browser profile only.

    Informatica button recipients

    One email address per line: the people the button adds to the external work notes list. With none listed the button refuses to run. Stored in this browser profile only.
